These items should be added directly to GitHub Issues so they can be tracked, implemented, and verified. This is the consolidated list; the issues have not yet been created in GitHub.

* Fix sidebar collapse: Make the sidebar collapse fully and reclaim the space. Currently, only a small portion disappears.
* Simplify global navigation: Remove “Working now” icons, “All projects,” and the redundant “Desk” view.
* Remove the top status bar: Remove the “Waiting on me” / “Nothing running” strip.
* Put the project picker at the top left: Allow switching between projects directly from the sidebar.
* Move project sections into the left sidebar: Place Overview, Documents, Tasks, Contacts, and other project sections there.
* Create a customizable project dashboard: Use the main project area for widgets such as documents, tasks, and activity that users can rearrange.
* Remove oversized project color blocks: Eliminate the large colored squares and rectangles that consume space without adding value.
* Add customizable project images and icons: Support uploading a custom image or choosing from approximately 30 familiar SVG icons, with selectable icon colors.
* Move “Lately” near the bottom: Retain the useful activity feed in a less prominent position.
* Improve space usage throughout: Reduce oversized decorative elements and unnecessary interface clutter.
* Place Settings at the bottom left: Label the entry “Settings” rather than “Appearance.” The existing settings dialog approach is acceptable.
* Fix the standalone appearance button: Ensure the dark-mode shortcut performs its intended action. Leave the working Appearance settings intact.
* Reposition the settings close button: Put the X in the top-right corner of the dialog’s outer header, outside the content area.
* Fix connection buttons: Clicking an unconnected service such as Google Drive must start its authorization and connection flow.
* Support disconnecting services: Provide a working Disconnect action for connected services such as Notion, and update the displayed connection status.
* Implement MCP client controls: Make the MCP client entry open a functional setup or management view.
* Implement “Connect something”: Open a usable service-selection and connection flow.
* Implement channel setup: Make Telegram, Slack, and other channel entries open working connection or configuration flows.
* Add Google Calendar task synchronization: Allow connecting Google Calendar and synchronizing project tasks. Treat this as a high-priority requirement.
* Show complete documents: Opening a project document should display its full contents.
* Improve PDF viewing: Display PDFs in an in-app viewer, with an “Open in new tab” button that opens the actual PDF for full reading.
* Fix document conversation navigation: Keep the useful document speech icon, but ensure users can reliably return from the conversation to Documents.
* Add a close control to document conversations: Provide an obvious X that closes the conversation panel and returns to the document.
* Make “Add someone” functional: Open a standard Add Contact form with name, phone number, email, Instagram, and other relevant contact details.
* Simplify contact presentation: Remove unnecessary people imagery or decorative contact elements.
* Keep team voice integrated into the interface: “Call the team” should activate voice in place, visibly change the button’s color/state, and remain active while users navigate.
* Fix voice shutdown: Turning voice off must stop microphone capture and ongoing voice playback, with a clear inactive state.
* Add “Message the team”: Provide an integrated text conversation area that remains accessible without opening a pop-up or obstructing navigation.
* Improve Help: Create a clear, well-organized guide covering setup, navigation, connections, documents, tasks, and using team voice and messaging effectively.
* Verify all interactive controls: Check buttons and links across the interface. Each should perform its intended action and show clear success, loading, or error feedback.
