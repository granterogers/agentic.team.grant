# HUMAN_BLOCKED — actions no software may perform

An item belongs here ONLY if it survives the §8 human-only filter:
repository code cannot do it, no official CLI can, no official API can, no safe
supported browser automation can, and it genuinely requires identity
verification, consent, payment, CAPTCHA, one-time secret retrieval, provider
policy, or a subjective human choice.

Each entry must state the EXACT action, with URLs and steps, per Grant's
standing instruction: *"Always be explicit with instructions!!! ... include full
instructions each and every time with URLs, steps to follow, etc."*
