# Autonomous run state (moved)

This file is no longer the mission record. It was a 3,363-line log that held four previous missions and one current
one, and the instructions in it could contradict each other.

- **The current mission:** `docs/agent/CURRENT-MISSION.md`.
- **Its machine state:** `docs/agent/EXECUTION-STATE.json`.
- **How to resume, stop or monitor a run:** `docs/agent/CONTINUITY.md`.
- **The full historical log, preserved unchanged:** `docs/agent/history/AUTONOMOUS-RUN-2026-10-14-full.md`. Search it
  for a term; do not read it whole.

Nothing in the historical log authorises a merge, a deploy, a spend or the end of current work. See the precedence
model at the top of `CLAUDE.md`.
