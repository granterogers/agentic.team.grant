# Final screenshots, 10 October 2026

Captured by `scripts/verify/surface-lab.ts` after the last code change of the finishing sprint (head after commit `357b6b3` plus the Jump-row
contrast fix). 1440x900 desktop and 390x844 phone, dark and light, Original look, slate palette, Soft glass, Soft depth. Colours are reduced to
96 so the folder stays small; the full-resolution captures are regenerated by the commands below.

```
WRITER=1 AXE=1 ONLY=pages,menus,settings,records,modules,chat,popovers,dialogs,toasts,writer,empty,auth DEVICES=desktop1440 SCHEMES=dark,light OUT=.out/final/desktop1440 npx tsx scripts/verify/surface-lab.ts
WRITER=1 AXE=1 ... DEVICES=phone390 ...
AXE=1 ONLY=records,modules,chat,empty DEVICES=desktop1440 SCHEMES=dark,light OUT=.out/final/records-desktop1440 npx tsx scripts/verify/surface-lab.ts
```

File name: `<surface>__<device>-<scheme>-slate.png`. The four `matrix-*.md` files are the lab's own per-cell verdicts.

| Run | Verified | Defect | Blocked |
|---|---|---|---|
| Writer, desktop 1440, both schemes | 96 | 0 | 8 |
| Writer, phone 390, both schemes | 90 | 0 | 14 |
| Records / modules / chat / empty (prototype project), desktop | 22 | 0 | 0 |

Blocked cells, and why (none is counted as verified): contact, document and task records need a record, and the stand-in office's project is
empty (they are verified in the prototype run above); module tint, layouts and the focused note are not offered on a phone board; `attention`
did not open in the stand-in office (no team page to go to).
