## Tiers

| tier | contents | cases | cost |
|---|---|---|---|
| 1 — permanent smoke | npm run tier1 — the routing corpus, the judged corpus, and the collaboration probe | ~111 | about 30 minutes, foreground, mostly the judge |
| 2 — readiness | Tier 1 plus every verify suite: npm run gate, then npm run e2e | ~111 | hours; before a release or a human acceptance phase |
| 3 — deep stress | systematic mutation of every Tier 1 case across all ten forms — SPECIFIED, NOT RUN | ~1110 | many hours, deliberately scheduled. Do not run it because it exists. |

Runtime is the constraint, not money: free models mean £0, GitHub Actions are
off (#17), and nothing may be hidden in the background.

## Read as ranges

The judge moves ±2 cases between runs of an unchanged corpus even pinned and at
`temperature: 0` (#229), and the routing figures moved by one case in two places
between two runs on 14 September. A tier read to single-case precision is
reading noise.
