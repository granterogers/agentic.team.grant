## Six defects that were live in Grant's office

Each was found by exercising something, not by reading it.

1. **A duty had been queued for eight hours.** `office.propose`, enqueued at
   22:15, attempt 0, no error anywhere — because nothing had failed. Migration
   0473 created the duty and its handler went into `src/office/pass.ts` in the
   same commit, and the deployed worker was built before it. **A migration is
   not a deploy.** The job completed inside the drain of the deploy that fixed
   it.

2. **`storagePath` had never reached a Slack message.** The checkpointed step
   that stores an artifact returned `documentId, pages, sources, stored, title`
   and no `path`, so `attachFile` never carried one and the notifier took its
   honest-degradation branch on **every artifact ever produced** —
   *"I could not make a link to it from here."* Both halves right alone.

3. **One request produced two reports.** The parent turn started an
   `artifact.report` and handed the instruction verbatim to a second
   specialist, who started another. Two near-identical PDFs in one project,
   seconds apart — the provenance defect CLAUDE.md names, manufactured by the
   office itself.

4. **`unarchive_project` raised instead of refusing.** ADR-0014's deferred
   constraint trigger meant any project whose sources had been disconnected —
   the ordinary way a project stops being used — could never be brought back,
   and the failure arrived as "the action failed" from a SECURITY DEFINER
   function at commit.

5. **The document sheet was broken on a phone and had never been captured.**
   `.docacts` has been a wrapping flex row since #152; at 390px Rename and
   Replaced by rendered one character per line, over the sheet's own padding.

6. **Two credentials needed Grant and appeared nowhere he looks.** Google's
   refresh token has been refused since the 17th and the Telegram chief bot
   token is missing. They are on My Tasks now.

## Three instruments that were worse than the product

The run found more wrong with the checking than with the thing being checked,
which is worth saying plainly.

- **`verify:judge` accused a working judge.** It reported 3/5 and "CANNOT
  discriminate"; the same model on the same corpus scored 5/5 twenty minutes
  later, because one pair spent its whole 16,000-token budget reasoning and
  returned nothing. And **the survey mode — the only way to pick a judge on
  evidence — had never run**, dying on `operator does not exist: text = integer`.
- **`verify:artifact`'s header claimed it checked `attachFile.storagePath`.**
  It rebuilt the path from values it already had and proved a URL mints for
  that. A comment claiming a property is worth nothing without a check.
- **A guard in the new routing code could not fail.** Deliberately removing it
  changed nothing across the whole corpus, and it also refused a real case.
  Deleted; the protection is a named property with a test now.

Every new detector in this run was deliberately broken, watched go red, and
restored. Nine such sabotages.

the most useful thing this run has to hand on: **eleven of the thirteen misses
were decided by the LITERAL trigram matcher, so the semantic layer was never
consulted.** "Which channel should we stop spending on?" went to finance;
"Work out who we should be talking to" went to operations. That is the thing to
look at next, not the threshold. Recorded in `docs/testing/e2e-2026-09-18.md`.
