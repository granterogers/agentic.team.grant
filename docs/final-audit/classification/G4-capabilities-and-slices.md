## G. Unmet ARCHITECTURAL properties (not features), with the smallest remediation
1. **Lifecycle has non-terminal states with no exit or escalation (MC7, slice 6, audit invariants 34-36).** A paused job with a non-resumable reason and no answer, and an unanswered blocker, never expire; `obligation_state` reads such a tree as `working`; `blocker_state='expired'` has no writer. Smallest fix: one sweep (SQL function called from the worker tick) that writes `expired` on blockers past `real_deadline` or an age ceiling and tells Grant once through `say_once`; add a `waiting_on_user`/`stuck` branch to `obligation_state` for a paused job with a non-resumable, unanswered reason. Add a poison-job / expiry suite.
2. **Authority boundary is not total (slice 3, AD3).** Four system duties (#389, needs Grant's option A/B/C), `google.revoke` (#390), write-capable attach doors (#393) and the telegram `repository_dispatch` (#391) sit outside `app.authorize_effect`. Smallest fix: #393 and #391 are mechanical (`mayWrite` or the CI ledger at the door); #389 waits on his choice, with B recommended for irreversible Slack/rotation duties.
3. **Gate precedence is only partial (slice 2, AD1 remainder).** `gates.ts` orders three gates; `understand` still runs after the plan/populate/teach early returns, so a plan + preference + question turn can lose a clause. Smallest fix: a characterisation-first change to run `understand` (or a cheap pre-classifier) once before the early returns, behind the existing `Turn`. ADR-0052 recorded the extra model call as the reason not to.
4. **Harness classification still rests on name-based signals (slice 5 residual).** `app.harness_job` was not converted to read the stored origin and the six legacy signals remain. Smallest fix: make it read the stored class first for jobs stamped after 0619 and keep the legacy signals only for the 16,466 legacy jobs; add the witness-parity check the audit asked for.
5. **The verification half of "architectural done" (section 46) is unmet.** The isolated replica suites (48 pass-lines in `run-all.sh`) are not in `npm run gate` (`scripts/e2e.ts` has no `isolated` hook). Smallest fix: a gate step that invokes `scripts/isolated/run-all.sh` (or a `gate:isolated` npm script) whenever a replica is available.
6. **Lifecycle copies still drift-prone (slice 6, engineering debt by the audit's own words).** `assertTransition` is dead code and `attempt < 4` is still hard-coded in `worker.ts` and `instruction.ts`. Smallest fix: read `max_attempts` from the job row; either wire or delete `assertTransition`.
7. Not architectural, recorded for completeness: AD2 (conversation = channel) is an ACCEPTED-DEBT decision (MC6, slice 7). The dashboard and voice answer binding is weaker than Telegram/Slack (#397, recorded).
