Fonts in this directory
=======================

Anybody
  Copyright The Anybody Project Authors (https://github.com/Etcetera-Type-Co/Anybody)
  SIL Open Font Licence 1.1
  https://openfontlicense.org
  Variable: weight 100-900, width 50%-150%. Latin subset.

Instrument Sans
  Copyright The Instrument Sans Project Authors
  (https://github.com/Instrument/instrument-sans)
  SIL Open Font Licence 1.1
  https://openfontlicense.org
  Variable: weight 400-700, width 75%-100%. Latin subset.

Both are self-hosted rather than linked, because Chromium in the capture
sandbox cannot reach fonts.googleapis.com — a linked font means every
screenshot is judged in the fallback face, which is how a typography note
becomes worthless.

Previously here, and removed 2026-09-10: Archivo and Schibsted Grotesk. Both
competent neo-grotesques, which was the problem — the same voice twice, and the
house style of every generated dashboard.
